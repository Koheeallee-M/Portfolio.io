# Developer Portfolio

A responsive, static portfolio website designed for GitHub Pages.

## Before publishing
1. Open `index.html` and replace `Ali` if you want a different display name.
2. Replace `YOUR_EMAIL@example.com`, `YOUR_USERNAME`, and `YOUR_LINKEDIN` with your real links.
3. In the PriceWhisper project card, replace `https://github.com/` with the actual repository URL.
4. Review the skills and project descriptions so they accurately reflect your current experience.
5. Preview by opening `index.html` in your browser.

## Publish with GitHub Pages
1. Copy the contents of this folder into the root of your portfolio repository.
2. Commit and push the files to the repository's `main` branch.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish. Your site URL will be shown in the Pages settings.

No build tools or backend are required.
